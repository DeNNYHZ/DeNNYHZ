### Selected Projects

- **BuildRoute** — internal logistics management app for a building materials store. Go (Gin/Fiber) + Flutter + PostgreSQL, with fleet route optimization (bin-packing + nearest-neighbor VRP), real-time GPS tracking over WebSockets, and JWT-based security hardening. Deployed at [`buildroute.dennyhz.dev`](https://buildroute.dennyhz.dev).
- **AutoTrack Pro** — mobile app for Indonesian automotive enthusiasts: odometer tracking, service reminders, GPS trip tracking, and leaderboards. Built with React Native + Expo.
- **infra-manager** — a Telegram bot for managing my Oracle Cloud VPS: container status, logs, backups, cost tracking, and safe restart/reboot with two-step confirmation, plus a Docker watchdog and Uptime Kuma heartbeat.
- **IT Support Ticketing & Dashboard** — internal system designed to replace ad-hoc IT support requests, with structured ticket numbering, an employee portal, and Telegram integration for status lookups.
- **Rate Limiting Performance Analysis** *(undergraduate thesis)* — compared Token Bucket, Leaky Bucket, and Sliding Window algorithms on a Go + Redis REST API under normal, spike, and DDoS traffic scenarios using JMeter and Vegeta. Cut P95 latency during DDoS from ~18,400 ms to ~1,190 ms while blocking 95–98% of malicious requests.
